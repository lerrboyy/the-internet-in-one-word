**Timesuck**

One word for the whole internet. You open it for one thing and an afternoon is gone — every site, feed, video and comment thread does the same thing to your time. The field was full of doomscrolling, feral and brainrot; nobody had named the bill.

## Entry

`Timesuck` — exactly one word, 8 characters. The program writes it to `/output/entry.txt` and verifies the write byte-for-byte.

## Run

```sh
OUTPUT_DIR=./out node main.ts
```

Node 22+, no dependencies, no network.
